# Portfólio · Emanuelle de Abreu

Portfólio pessoal e currículo online feito com **HTML, CSS e JavaScript puro**, sem frameworks. Reúne quem eu sou, meus projetos, minhas certificações e formas de contato em uma página única, com animações 3D e fundo interativo.

🔗 **Acesse:** [emanuelleabreuc.github.io/portfolio](https://emanuelleabreuc.github.io/portfolio/)

![Prévia do portfólio](./Captura%20de%20tela%202026-01-13%20193843.png)

## Sobre mim

Graduanda em Engenharia da Computação (6º período), com conhecimentos em C#, Java, Python, HTML/CSS e SQL, além de hardware, elétrica/eletrônica e AutoCAD. Inglês nível B2.

## Seções

- **Início**: apresentação com foto e cena 3D que acompanha o mouse
- **Sobre**: resumo profissional e cubo giratório com as tecnologias que uso
- **Projetos**: cards com links para os projetos (C, C#/WPF + SQL Server, Python, sites e eletrônica)
- **Certificações**: cursos, eventos e formações concluídos
- **Contato**: e-mail, telefone, redes sociais e formulário que abre o e-mail já preenchido

## Recursos

- Efeito de inclinação 3D (tilt) e brilho que segue o cursor nos cards
- Fundo animado em `<canvas>` com partículas conectadas, que reagem ao mouse
- Animações de entrada ao rolar a página e menu que destaca a seção atual
- Layout responsivo, para celular e desktop
- Respeita a preferência de **movimento reduzido** (`prefers-reduced-motion`) do sistema

## Tecnologias

- HTML5
- CSS3 (variáveis, transformações 3D, animações)
- JavaScript (IntersectionObserver, Canvas API)
- [Ionicons](https://ionic.io/ionicons) e Google Fonts (Poppins e Space Grotesk)

## Como rodar localmente

Não precisa instalar nada. Clone o repositório e abra o `index.html` no navegador:

```bash
git clone https://github.com/emanuelleabreuc/portfolio.git
```
